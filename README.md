### Windows 10/11 Privacy & Performance Optimization Tool

### A lightweight script designed to clean Windows from unnecessary Microsoft software, bloatware, ads, and unwanted background components.

### Key features
- Remove OneDrive
- Remove Microsoft Copilot
- Uninstall preinstalled UWP apps
- Disable ads and personalized recommendations
- Disable Windows Tips and Suggested Content
- Clean up unnecessary startup apps
- Disable unwanted telemetry
- Remove preinstalled Windows bloatware

### Usage

1) Download the .zip file on the main page of the GitHub and extract the .zip file to your desired location
2) Right-click the .exe file and click on "Run As Administrator"
3) Select the actions you want to perform.

You can choose to either 'Debloat' or 'Revert'. Depending on your choice, either one will run specific code to either debloat your Windows 10 machine.

Remember this script **NEEDS** to be run as admin in order to function properly.

## The Debloat switch choice runs the following functions

Debloat,
Remove-Keys,
Protect-Privacy,
Stop-EdgePDF (If chosen)

## The Revert switch choice runs the following functions

Revert-Changes,
Enable-EdgePDF

The Revert option reinstalls the bloatware and changes your registry keys back to default. 

## The scheduled tasks that are disabled are

XblGameSaveTaskLogon,
XblGameSaveTask,
Consolidator,
UsbCeip,
DmClient

These scheduled tasks that are disabled have absolutely no impact on the function of the OS.
